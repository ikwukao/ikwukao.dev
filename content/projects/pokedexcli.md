## Overview

**Pokedex CLI** is a command-line application written in Go that interacts with the PokéAPI to explore Pokémon data through an interactive terminal interface.

The project was built as a practical exercise in Go backend fundamentals, with emphasis on HTTP requests, JSON decoding, command dispatch, application state, caching, and clean separation between API interaction and CLI behavior.

---

## Key Features

- Interactive command-line interface.
- API-backed Pokémon location exploration.
- Pokémon lookup and inspection.
- JSON response decoding into Go structures.
- Stateful command handling.
- HTTP client integration.
- In-memory caching to reduce unnecessary API requests.
- Clear command and response flow designed for terminal use.

**HTTP Clients · APIs · JSON · Go Data Modeling · CLI Architecture · Error Handling**

## Lessons Learned

Pokedex CLI provided a practical foundation for understanding how Go applications communicate with external services and how backend concepts can be expressed in a small, maintainable command-line application.
