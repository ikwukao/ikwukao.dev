## Overview

**BookBot** is a command-line text analysis program written in Python. It reads a book from disk, analyzes its contents, and produces useful statistics about the text.

The project is intentionally small, but it establishes fundamentals that are important in larger backend and automation systems: reading external data, transforming data, calculating structured results, and presenting those results consistently.

## Engineering Highlights

* Reads book content from files.
* Counts total words in a document.
* Calculates character frequencies.
* Normalizes text before analysis.
* Transforms raw dictionaries into sorted report data.
* Separates data processing into focused functions.
* Produces a readable command-line report.

## Engineering Focus

Python Fundamentals · File I/O · Data Processing · Dictionaries · CLI Design

## Lessons Learned

BookBot reinforced the importance of breaking even small programs into focused functions. The same principles of clear data flow and separation of responsibilities scale naturally into larger backend applications.
