## Overview

**Asteroids** is a Python game project built to strengthen object-oriented programming and event-driven application design through an interactive arcade-style environment.

Although smaller than the backend and infrastructure projects in the portfolio, it provided practical experience modeling application state as cooperating objects and coordinating those objects inside a continuous runtime loop.

## Engineering Highlights

* Modeled game entities as independent objects.
* Implemented an application/game loop.
* Added keyboard-driven player interaction.
* Managed object movement and state updates.
* Implemented collision detection and response.
* Organized behavior into reusable classes.
* Practiced inheritance and composition.
* Separated game logic into manageable modules.

## Engineering Focus

Object-Oriented Design · State Management · Event Loops · Collision Detection · Python

## Lessons Learned

The project strengthened my understanding of how stateful applications evolve over time and how clear object boundaries can make interactive systems easier to reason about and extend.
